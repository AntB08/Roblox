# It Talks Back: animation files

Generated by `lune run lune/build-animations` from the game's procedural animation code
(`src/client/FX/MonsterAnimator.luau`), so they match what the game shows now. Re-run it after
changing that code. (Editing in Studio is the other way. Then the published version is the truth.)

| File | What |
|---|---|
| `ItTalksBack_Animations.rbxm` | **Start here.** Folder with the monster rig `TheTenantRig` (all 11 animations in its `AnimSaves`) and `PlayerAnimations_R15` (crouch). |
| `Monster_*.rbxm` | Each monster animation on its own (KeyframeSequence). |
| `Player_*.rbxm` | R15 crouch animations (KeyframeSequence), for any R15 character. |

Monster: Idle, Walk, Run, Listen, Speak, Dormant (loops) · Grab, Snuff, Look, Vanish, Emerge (one-shots).
Player: CrouchIdle, CrouchWalk (loops).

## Import and publish (Roblox Studio)
1. Open your place. Drag `ItTalksBack_Animations.rbxm` into the 3D view (or right-click Workspace →
   *Insert from File...*). You get the rig standing at the origin.
2. **To edit:** open *Avatar → Animation Editor*, click the rig, then *... → Load* and pick an animation
   (the editor lists everything in the rig's `AnimSaves`). Tweak the keyframes.
3. **To publish:** in the Animation Editor, *... → Publish to Roblox* (or right-click a KeyframeSequence →
   *Save to Roblox*). Copy the asset id it gives you.
4. Paste each id into `src/shared/Config/Assets.luau` → `Animations.Monster.<Name>` /
   `Animations.Player.<Name>` as `"rbxassetid://<id>"`, and record it in `assets/ASSETS.md`.
   - Monster: the game switches to your published animations once `Idle` has an id. Fill in all 11, because
     states without an id fall back to Idle.
   - Player crouch: used once both `CrouchIdle` and `CrouchWalk` have ids. Publish them on an R15
     dummy (*Avatar → Rig Builder → R15*).
5. Delete the imported rig from Workspace when you're done (the game builds its own).

Publish animations under the same owner as the game (your account or your group), or they won't play.
