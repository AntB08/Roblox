# The Tenant: high-detail meshes

`TheTenant.glb` holds one organic mesh per body part of the monster rig (103 meshes, about 25k triangles),
named `M_<PartName>`, with three textures (`textures/flesh.png`, `bone.png`, `claw.png`). It's an original design,
generated by code from the rig itself so every mesh fits its joint:

```
lune run lune/export-rig-spec          # rig -> build/rig_spec.json
python3 tools/build_monster_mesh.py    # -> TheTenant.glb, textures, src/server/Config/MonsterMeshes.luau
```

Without the meshes, the game uses rounded primitive shapes, so nothing breaks either way.

## Put them in the game (one time, in Studio)
1. **File/Home → Import 3D** and pick `assets/meshes/TheTenant.glb`.
2. In the import window:
   - **Merge Meshes: off.** You need one MeshPart per body part.
   - **Rig: none / static.** The game rigs it itself.
   - Leave the textures on, and keep the scale at 1. The game resizes each piece anyway.
3. Import. A Model appears in Workspace. **Rename it to `TenantMeshes` and drag it into ServerStorage.**
4. Press Play. The monster now wears the meshes: same skeleton, same animations.

If the monster's face points backward (some importer settings turn models around), open
`src/server/Game/MonsterRig.luau` and set `MESH_ROTATION = CFrame.Angles(0, math.pi, 0)`.

Performance: about 25k triangles in total; MeshParts lower their detail automatically at a distance
(`RenderFidelity = Automatic`). The animation only runs within about 160 studs of the monster.
