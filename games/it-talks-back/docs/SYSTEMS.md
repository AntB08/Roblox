# Systems: It Talks Back

## Server services (src/server/Services, higher Priority inits first)
| Service | Job |
|---|---|
| NoiseService (80) | `emit(pos, radius, kind, player)`; measures footsteps from server-side velocity |
| MovementService (70) | sprint/crouch/flashlight intent → WalkSpeed, stamina, the SpotLight |
| FuseService (60) | fuse spawns, carrying, generator, power on, exit gate |
| HideService (60) | closets: hide/leave, "hidden since" for the monster |
| CageService (55) | cage put/rescue (hold prompt, loud) |
| VoiceService (50) | picks lines (Server/Config/Lines.luau), optional TextGenerator + TextService filter, `MonsterSpeak` |
| CalloutService (50) | preset callouts → teammates + the monster |
| SpeechService (30) | voice transcripts (client STT → Spoke): noise, room words = callouts, AI replies when close. Text chat hidden |
| MonsterService (40) | rig + state machine (Dormant/Patrol/Investigate/Chase/Search/PullOut/Cooldown) |
| TaskService (20) | nightly checklist: fuses + Radio/Candles/Key, opens the exit when all done |
| VarietyService (15) | per-night personality, twist, spawn; mid-round surge/knock/vanish events |
| VoiceGateService (170) | voice-chat-only: kicks players without voice (not in Studio; lets players in if the check fails) |
| RoundService (10) | lobby → playing → results loop; escapes; rewards |
Shared helpers (not services): `Server/Game/State.luau` (statuses, round state), `Map.luau` (tag lookups), `MonsterRig.luau`.

## Remotes (src/shared/Net/Remotes.luau)
ToServer (Guard + rate limited): Spoke(text ≤ 200), SetSprint(bool), SetCrouch(bool), SetFlashlight(bool), Callout(room ∈ Callouts), LeaveHide(), SetSetting, ClientError.
ToClient: PlaySoundAt(key, position, times), MonsterSpeak(text, kind), RoundMessage(title, subtitle, seconds), CalloutShown(name, room), Caught(name, isYou), Notify.

## Replicated attributes
- Player: `Status` (Lobby/Alive/Hidden/Caged/Escaped), `Stamina` (0..1), `Sprinting`, `Crouched`, `Flashlight`, `CarryingFuse`, `CarryingKey`, `Coins`.
- Workspace: `Personality`, `Twist`, `LightsOut`, `Night`, `TaskList`, `Task_<Id>_Done/Goal`, `ExitOpen`, `RoundState`, `IntermissionEndsAt`, `RoundEndsAt` (GetServerTimeNow time), `FusesInserted`, `FusesTotal`, `PowerOn`.
- Monster model (tag `Monster`): `Mood` (Dormant/Calm/Alert/Chase), `TargetUserId`.

## Map tags (generated by tools/build_map.py)
RoomVolume(RoomName), PatrolPoint(Room), FuseSpawn(Room), PlayerStart(Index), MonsterSpawn, Closet (Model with Inside/Front),
Generator, FuseSlot(Index), ExitGate, ExitSign, ExitZone, CageDoor, CageInside, CageOutside, HouseLight(Room, BaseBrightness), RadioSpawn, CandleSpawn, KeySpawn (Room), Doorway (A, B, Door). Runtime tags: Radio(On), Candle(Lit), KeyItem.

## Data schema (src/server/Data/Schema.luau)
Coins, Stats {Rounds, Escapes, Rescues, TimesCaught, FusesInserted, PlaySeconds, ...}, Settings.

## LiveConfig keys
`monster_ai_dialogue` (bool, default true): kill switch for TextGenerator lines. `coin_multiplier`, `motd`.

## Analytics custom events
RoundEnded, PlayerCaught, PlayerEscaped, CalloutUsed. Onboarding: DataLoaded → FirstRound → FirstFuse → FirstEscape.

## Animation and cutscenes (all procedural, no uploaded animation assets)
- Meshes: `tools/build_monster_mesh.py` → `assets/meshes/TheTenant.glb` (+ textures, `Config/MonsterMeshes.luau`). Imported into `ServerStorage.TenantMeshes`, `MonsterRig` welds `M_<Part>` MeshParts onto the rig and hides the primitives (see `assets/meshes/README.md`).
- Rig: `src/server/Game/MonsterRig.luau` — 103 Motor6Ds (+12 mouth feelers since the 91-joint version): (4-joint spine, 4-joint neck, skull, jaw, 2-joint tongue, eyelids, clavicles, arms, 2-joint thumbs, 4 three-joint fingers per hand, legs with toes, 4 five-segment back tendrils, 6 two-joint cloth rags, 6 two-joint mouth feelers) + welded decor (ribs, teeth, claws, sockets, spikes, rags). Parts are ellipsoid/wedge SpecialMeshes (`shape` in the spec). Spec in `MonsterRig.SPEC`.
- Monster: `src/client/FX/MonsterAnimator.luau` — authored on a body layer, expanded to the 103 joints (curved spine/neck, finger curl and twitch, tongue, blinks, tendril waves); layered target pose + per-joint damped springs (follow-through, overshoot), distance-driven gait (poses: idle, creep walk, chase sprint, listen, speak, grab, snuff, look,
  vanish glitch, emerge), driven by monster attributes `Mood`, `Action` + `ActionUntil` (server `MonsterService.act`).
  Applied each frame by `MonsterFxController`. Action lengths must match `ACTION_LENGTH` there.
- Catch: server lifts the victim in front of it for 1.6 s (anchored), then cages them.
- Players: `CrouchPoseController` layers a squat on R15 characters with `Crouched` (everyone sees it).
- Cutscenes: `CutsceneController` (night intro, catch close-up, escape shot), letterbox/title in `Overlay`.
