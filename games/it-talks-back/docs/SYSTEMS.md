# Systems: It Talks Back

## Server services (src/server/Services, higher Priority inits first)
| Service | Job |
|---|---|
| NoiseService (80) | `emit(pos, radius, kind, player)`; measures footsteps from server-side velocity |
| MovementService (70) | sprint/crouch/flashlight intent → WalkSpeed, stamina, the SpotLight |
| FuseService (60) | fuse spawns, carrying, generator, power on, exit gate |
| HideService (60) | closets: hide/leave, "hidden since" for the monster |
| CageService (55) | cage put/rescue (hold prompt, loud) |
| VoiceService (50) | picks lines (Server/Config/Lines.luau), optional TextGenerator + TextService filter, `MonsterSpeak` |
| CalloutService (50) | preset callouts → teammates + the monster |
| SpeechService (30) | voice transcripts (client STT → Spoke): noise, room words = callouts, AI replies when close. Text chat hidden |
| MonsterService (40) | rig + state machine (Dormant/Patrol/Investigate/Chase/Search/PullOut/Cooldown) |
| TaskService (20) | nightly checklist: fuses + Radio/Candles/Key, opens the exit when all done |
| RoundService (10) | lobby → playing → results loop; escapes; rewards |
Shared helpers (not services): `Server/Game/State.luau` (statuses, round state), `Map.luau` (tag lookups), `MonsterRig.luau`.

## Remotes (src/shared/Net/Remotes.luau)
ToServer (Guard + rate limited): Spoke(text ≤ 200), SetSprint(bool), SetCrouch(bool), SetFlashlight(bool), Callout(room ∈ Callouts), LeaveHide(), SetSetting, ClientError.
ToClient: MonsterSpeak(text, kind), RoundMessage(title, subtitle, seconds), CalloutShown(name, room), Caught(name, isYou), Notify.

## Replicated attributes
- Player: `Status` (Lobby/Alive/Hidden/Caged/Escaped), `Stamina` (0..1), `Sprinting`, `Crouched`, `Flashlight`, `CarryingFuse`, `CarryingKey`, `Coins`.
- Workspace: `Night`, `TaskList`, `Task_<Id>_Done/Goal`, `ExitOpen`, `RoundState`, `IntermissionEndsAt`, `RoundEndsAt` (GetServerTimeNow time), `FusesInserted`, `FusesTotal`, `PowerOn`.
- Monster model (tag `Monster`): `Mood` (Dormant/Calm/Alert/Chase), `TargetUserId`.

## Map tags (generated by tools/build_map.py)
RoomVolume(RoomName), PatrolPoint(Room), FuseSpawn(Room), PlayerStart(Index), MonsterSpawn, Closet (Model with Inside/Front),
Generator, FuseSlot(Index), ExitGate, ExitSign, ExitZone, CageDoor, CageInside, CageOutside, HouseLight(Room, BaseBrightness), RadioSpawn, CandleSpawn, KeySpawn (Room). Runtime tags: Radio(On), Candle(Lit), KeyItem.

## Data schema (src/server/Data/Schema.luau)
Coins, Stats {Rounds, Escapes, Rescues, TimesCaught, FusesInserted, PlaySeconds, ...}, Settings.

## LiveConfig keys
`monster_ai_dialogue` (bool, default true): kill switch for TextGenerator lines. `coin_multiplier`, `motd`.

## Analytics custom events
RoundEnded, PlayerCaught, PlayerEscaped, CalloutUsed. Onboarding: DataLoaded → FirstRound → FirstFuse → FirstEscape.
