## Export Image as SGI

 Export Image as SGI

 Formats
 sgi

## Overview

## The SGI Export dialog

 Silicon
 Graphics Images (SGI), is a raster graphics file format
 created by Silicon Graphics.

## Options

 Compression type

 No compression

 The image will be stored uncompressed.

 RLE compression

 The image will be stored using Run-Length Encoding.

 Aggressive RLE (not supported by SGI)

 The image will be stored using an aggressive form of
 Run-Length Encoding.
