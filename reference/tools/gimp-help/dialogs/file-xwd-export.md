## Export Image as Xwd

 Export Image as Xwd

 Export Image as X window dump

 Formats
 xwd

## Overview

 You can export your image in xwd format, which is short for X
 window dump format, when you choose the .xwd extension,
 or explicitly choose X window dump as file type in the
 export dialog.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
