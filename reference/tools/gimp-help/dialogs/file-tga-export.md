## Export Image as TarGA

 Export Image as TarGA

 Formats
 tga

## Overview

## The TGA Export dialog

 Truevision
 TGA, or also known as TARGA, is a raster graphics file format
 created by Truevision.

## Options

 Use RLE compression

 When checked, the image will be compressed using
 Run-Length Encoding, otherwise it will be
 uncompressed. Using RLE should in general produce smaller files.

 Origin

 This setting allows you to choose what to use as origin of the
 image. This will only be used internally to store the image. It
 will not have any visual difference. Choices are:

 Bottom left

 The image data is stored starting from the bottom left
 corner and then going upward.

 Top left

 The image data is stored starting from the top left corner
 and from there going down.
