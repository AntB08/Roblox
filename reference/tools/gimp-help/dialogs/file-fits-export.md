## Export Image as FITS

 Export Image as FITS

 Export Image as Flexible Image Transport System

 Formats
 fits

## Overview

 You can export your image in fits format, which is short for
 Flexible Image Transport System format, when you choose
 the .fits extension, or explicitly choose
 Flexible Image Transport System as file type in the
 export dialog.
 This image format is commonly used for astronomical images.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
