## Export Image as Qoi

 Export Image as Qoi

 Export Image as Quite OK Image

 Formats
 qoi

## Overview

 You can export your image in qoi format, which is short for Quite
 OK Image format, when you choose the .qoi
 extension, or explicitly choose Quite OK Image as file
 type in the export dialog.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
