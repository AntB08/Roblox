## Overview

## The SUN Rasterfile Export dialog

 Sun Raster
 was a raster graphics file format used on SunOS by Sun
 Microsystems. This format does not support transparency.

## Options

 Data formatting

 This setting allows you to choose whether the image should be
 stored as Standard (uncompressed data), or as
 Run-Length Encoding (compressed data).
 The latter should in general produce smaller files.
