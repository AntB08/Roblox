## Overview

 AVIF stands for AV1 Image File Format. It is an image file format
 specification for storing images or image sequences compressed with AV1
 in the HEIF container format.

 According to tests, AVIF showed better compression efficiency than JPEG
 as well as better detail preservation, fewer blocking artifacts and less
 color bleeding around hard edges in composites of natural images, text,
 and graphics.
 Most browsers support AVIF natively.
