 Export Image as OpenRaster

 Export Image as ORA

 Formats
 ora

## Overview

 You can export your image in
 OpenRaster
 format, when you choose the .ora extension, or explicitly
 choose OpenRaster as file type in the export dialog.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
