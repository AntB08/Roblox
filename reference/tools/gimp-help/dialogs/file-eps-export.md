## Overview

 EPS, or Encapsulated PostScript, is, as the name suggests,
 a format that encapsulates a PostScript document, that is usable as a
 graphics file format. For more information see
 Encapsulated
 PostScript.

 It is essentially a
 PostScript
 program saved as a single file that can include an image preview of the
 final output.
