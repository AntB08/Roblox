## Export Image as PFM

 Export Image as PFM

 Formats
 pfm

## Overview

 You can export your image in PFM format, when you choose the
 .pfm extension, or explicitly choose PFM
 as file type in the export dialog.

 This is a another variant of the
 Portable Anymap formats. The
 PFM format saves the image using floating point values for each pixel.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
