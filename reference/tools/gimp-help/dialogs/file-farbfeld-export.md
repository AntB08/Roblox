 Formats
 farbfeld

 Formats
 .ff

## Overview

 You can export your image in farbfeld format, when you choose
 the .ff extension, or explicitly choose
 Farbfeld as file type in the export dialog.

 There are no settings to choose from. No export dialog will open after
 you have chosen your filename. It will automatically start the export.
