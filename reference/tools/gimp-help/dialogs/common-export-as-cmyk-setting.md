Export as CMYK

 If you have a CMYK profile
 assigned to your image as soft-proofing profile, this setting can
 be checked to have your image exported using that CMYK profile.
 This is sometimes required when you have your image professionally
 printed. Your printing company will tell you if this is needed.

 If this setting is disabled, you don't have a soft-proofing profile
 set for this image yet. See assigning a
 Soft-Proof
 Profile.

 The name of the CMYK profile that is assigned to this image will
 be shown below this setting.
