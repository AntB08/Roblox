## Overview

 Photoshop is a well known image editor. This export dialog allows you
 to export in Photoshop's native PSD format.

 You can export your image in this format when you choose the
 .psd extension, or explicitly choose Photoshop
 image as file type in the export dialog.

 Some considerations when exporting to a PSD. Not all blending modes can
 be converted to an exact equivalent between GIMP and
 Photoshop. For many blending modes, the
 legacy layer
 modes are closer to Photoshop's equivalents. However, legacy
 layer modes do not support setting the
 composite mode.
 Photoshop often uses the equivalent of our
 Clip to Backdrop composite mode. There it is called
 Blend Clipped Layers as Group. If you want to support
 that, you should not use legacy layer modes.
