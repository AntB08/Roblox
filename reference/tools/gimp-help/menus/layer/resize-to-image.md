## Layers to Image Size

 Layer
 Size managing
 Resize selected layers to image size

 The Layers to Image Size command resizes the
 layer boundaries to match the image boundaries, without moving the
 contents of the selected layers with respect to the image.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Layers to Image Size
 .

 From the
 Layers Dialog, you
 can access it through the Layers to Image Size
 command of its context menu.
