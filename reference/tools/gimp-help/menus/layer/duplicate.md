## Duplicate layers

 Layer
 Stack managing
 Layer duplicate

 Duplicate Layers

 The Duplicate Layers command adds a copy of
 each selected layer to the image.
 The name of each new layer is the same as the name of the original layer,
 but with copy or a number appended to it.

 Note that if there are any parasites
 attached to the selected layers, they are not duplicated.
