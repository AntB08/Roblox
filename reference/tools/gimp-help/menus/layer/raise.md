## Raise Layers

 Layer
 Stack managing
 Move selected layers one position up

 The Raise Layers command raises the selected
 layers one position in the layer stack. If the selected layers
 already start at the top, or if there is only one layer, this menu entry is
 disabled.

## Activating the Command

 You can access this command from the main menu through
 Layer
 Stack
 Raise Layers
 .

 You can also access it by clicking the up-arrow icon at the bottom
 of the Layers dialog.
