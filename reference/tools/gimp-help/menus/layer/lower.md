## Lower Layers

 Layer
 Stack managing
 Lower layers

 The Lower layers command lowers the selected
 layers one position in the layer stack. If the selected layers already end
 at the bottom of the stack, or if there is only one layer, this menu entry
 is disabled.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Stack
 Lower Layers
 .

 You can also access it by clicking on the down-arrow icon at the
 bottom of the Layers dialog.
