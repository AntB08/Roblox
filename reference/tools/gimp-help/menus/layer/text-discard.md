## Rasterize, Revert Rasterize

 Layer
 Rasterize

 Layer
 Revert Rasterize

 Text
 Discard information

 Vector
 Discard information

 When you add text, vector or link layers to an image,
 GIMP stores specific information for that
 layer type.
 This command lets you discard this information, transforming the selected
 layers into normal bitmap layers.

 Note that if you try to perform a graphic operation like painting to one
 of these special layer types, it will blink and show a warning that you
 need to rasterize the layer first. By undoing or using
 Revert Rasterize you can revert the layer back to
 the layer type it was before rasterizing.

 This command only appears in the Layer menu
 if at least one relevant layer is selected.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Rasterize
 . If the layer has been rasterized previously, the
 command will be named Revert Rasterize.

 From the
 Layers Dialog, you
 can access it through the Rasterize
 command of its context menu.
