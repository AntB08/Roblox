 Apply Layer Masks (command)

 The Apply Layer Masks command merges the
 selected layer masks with the selected layers. The transparency information
 in the layer masks is transferred to the alpha channels of their respective
 layers. If a layer doesn't have an alpha channel, it is created. When that
 is done, the layer masks are removed.

 If the selected layers do not have layer masks, this menu entry is
 disabled.

 See the Layer Masks section for
 more information.
