## 
 The Transparency Submenu

 Layer
 Submenu
 Transparency

 The Transparency submenu contains commands
 which use or affect the alpha channel of the active layer. Some of these
 commands can work with multiple selected layers.

## Activating the Submenu

 You can access this submenu from the main menu through

 .
