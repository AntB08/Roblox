## Text to Path

 Layer
 Text
 to Path

 Text
 to Path

 This command creates a path from the outline of each selected text layer.
 Each path can be managed through the
 Paths Dialog. For more information
 see also Text to Path
 in Text Management.

 This command only appears in the Layer menu
 if at least one text layer is selected.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Text to Path
 .

 From the
 Layers Dialog, you
 can access it through the Text to Path
 command of its context menu.
