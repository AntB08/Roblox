## Select Top Layer

 Layer
 Stack managing
 Select top layer

 The Select Top Layer command makes the top
 layer in the stack the selected layer for the image and highlights it in
 the Layers dialog. If the selected layers start at the top of the
 stack, this menu entry is disabled.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Stack
 Select Top Layer
 .

 You can also use the keyboard shortcut Home.
