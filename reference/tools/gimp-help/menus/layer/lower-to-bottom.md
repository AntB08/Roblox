## Layers to Bottom

 Layer
 Stack managing
 Lower selected layers to the bottom of stack

 The Layers to Bottom command lowers the selected
 layers to the bottom of the layer stack. If the selected layers already end
 at the bottom of the stack, or if there is only one layer, this menu entry
 is disabled.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Stack
 Layers to Bottom
 .

 You can also access it by pressing the Shift key
 and clicking on the down-arrow icon at the bottom of the
 Layers dialog.
