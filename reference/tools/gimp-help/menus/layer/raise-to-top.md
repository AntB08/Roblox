## Layers to Top

 Layer
 Stack managing
 Move selected layers to the top of stack

 The Layers to Top command raises the selected
 layers to the top of the layer stack. If the selected layers already start
 at the top, or if there is only one layer, this menu entry is disabled.

## Activating the Command

 You can access this command from the main menu through

 Layer
 Stack
 Layers to Top
 .

 By pressing the Shift key and clicking on the
 up-arrow icon at the bottom of the Layers dialog.
