## Help

 Help

 The Help command displays the
 GIMP User Manual in your default browser.

 You can choose whether you prefer to use a locally installed copy of the
 manual, or the online version, in the Help
 System section of the Preferences dialog.

 If the help does not seem to work when you have selected local help,
 please verify that the GIMP User Manual is installed on
 your system. See the link above for more information.
