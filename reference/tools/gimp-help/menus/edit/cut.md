 Cut

 The Cut command deletes the contents of the
 image's selections, and saves them in a clipboard so that they can
 later be pasted using Paste,
 Paste In Place, or one
 of the many Paste as commands.
 If there is no selection, the entire current layer is cut. The areas whose
 contents are cut are left transparent, if the layer has an alpha channel,
 or filled with the layer's background color, otherwise.

 The Cut command only works on the current
 active layer. Any layers above or below the active layer are ignored.
