## Paste As Single Layer In Place

 Layer
 Paste

 Paste

 Paste as Single Layer in Place

 The Paste as Single Layer In Place command
 creates a new layer in the active image and pastes the clipboard contents
 at the exact coordinates the contents was originally copied from.

 This feature is available for both the regular clipboard and named buffers.

## Activating the Command

 You can access this command from the main menu through
