 Paste

 The Paste command places the contents of
 the clipboard from the last Copy or Cut
 command into the current image. The pasted section becomes a
 new layer, which is added above the currently active layer.

 To paste the section as a floating selection, without
 creating a new layer, see Paste as
 Floating Data.
