## Selection From Paths

 Selection
 Create a selection from Paths

 The Selection From Paths command transforms the
 selected paths into a selection.
 If a path is not closed, the command connects
 the two end points with a straight line. The original path is unchanged.

## Activating the Command

 You can access this command from the main menu through

 Select
 Selection From Paths
 .

 In addition, you can click on the
 Path to Selection button

 in the Paths dialog to access the command.

 You can also use the keyboard shortcut
 ShiftV.
