## Remove Holes

 Selection
 Remove Holes

 Remove Holes

 This command removes the holes of a selection. Holes are unselected or
 partially selected areas in the selection.

## Activating the Command

 You can access this command from the main menu through

 Select
 Remove Holes
 .
