 Hue

 The slider and the + and
 - buttons allow you to select a hue in the
 color wheel (-180°, 180°).

 Chroma

 Chroma is the purity of the color. Moving this 
 slider makes colors more or less pure.

 Lightness

 This slider and the + and
 - buttons allow you to select a value
 (luminosity): -100, 100.
