## Rearrange Colormap

 Colormap
 Rearrange

 Rearrange Colormap

## The Rearrange Colormap window

 This command allows you to re-organize colors in the palette of
 indexed images. It doesn't modify the image. You
 can't add or remove colors; for that, see
 The Indexed Palette Dialog.

 If your image is not indexed, this command is disabled.

## Activating the Command

 You can access this command from the main menu through

 Colors
 Map
 Rearrange Colormap…
 .

 You can also access it from the
 Colormap
 Dialog using the right-click context menu

 Rearrange Colormap…
 .

## Using the Rearrange Colormap dialog

 You can drag and drop colors using the mouse to rearrange the colormap.
 You can sort colors based on Hue, Saturation and Value by using the
 buttons. You can also reverse or reset the order of the colors.

 Another way to sort a colormap is by using the
 Sort Palette… context menu
 command available in the
 Palettes Dialog.
