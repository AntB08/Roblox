## Linear Invert

 Colors
 Linear Invert

 Linear Invert colors

 The Linear Invert command inverts all the color
 components except the alpha channel in the current layer in linear light.
 Dark areas become bright and bright areas become dark.

 Do not confuse this command with the
 Invert Selection command.

## Activating the Command

 You can access this command from the main menu through

 Colors
 Linear Invert
 .
