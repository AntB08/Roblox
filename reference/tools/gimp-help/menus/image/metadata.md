 Metadata

 Metadata are information about a document, embedded in the document. For GIMP, 
 they are image metadata.

 PNG, JPEG, TIFF and WebP preserve existing metadata.

 You can set defaults to enable or disable exporting metadata in all affected 
 file formats on whether you want complete privacy or not. Select 
 EditPreferences,
 then select Image Import & Export and go to the
 section Export Policies.
