## Rotation

 Rotation

 You can rotate the image using the rotation commands on the
 Transform submenu of the
 Image menu. These commands work on the whole image.

 Rotating by 90° clockwise or counter-clockwise can be used to change
 between Portrait and Landscape orientation. Rotating by 180° can be used
 to turn the image upside down.
 These three common angles are available as commands in the submenu.

 Use arbitrary rotation to rotate the image at any angle. This
 command behaves like the Rotate Tool.

 To instead rotate a selection or a layer, use the
 Rotate Tool. You can also
 rotate a layer by using the
 Layer Transform menu.

## Activating the Commands

 You can access the Rotate 90 degrees CW
 command from the main menu through

 Image
 Transform
 Rotate 90 degrees CW
 .

 You can access the Rotate 90 degrees CCW
 command from the main menu through

 Image
 Transform
 Rotate 90 degrees CCW
 .

 You can access the Rotate 180°
 command from the main menu through

 Image
 Transform
 Rotate 180°
 .

 command from the main menu through
