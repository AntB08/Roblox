## Flip Horizontally; Flip Vertically

 Flip

 You can flip the image, or turn it over like a
 card, by using the Flip Horizontally or
 Flip Vertically commands.
 These commands work on the whole image. To flip a selection, use the
 Flip Tool.
 To flip a layer, use the functions of the

 Layer
 Transform

 menu or the
 Flip Tool.

## Activating the Commands

 You can access the Flip Horizontally
 command from the main menu through

 Image
 Transform

 .

 command from the main menu through
