 Color Management

 This menu item opens a submenu allowing you to manage color
 display management on your system.
 These settings only affect the current display of an image. You can have
 multiple views of an image, each with their own color management view
 settings.

## Activating the Submenu

 You can access this submenu from the main menu through

 View
