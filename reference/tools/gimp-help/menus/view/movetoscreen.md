 Move to Screen

 The Move to Screen submenu allows to display
 GIMP on a different screen connected to your device.

## Activating the Submenu

 You can access this submenu from the main menu through

 View
 Move to Screen
 .

## Contents of the Move to Screen submenu

 Open Display…

 This is an experimental functionality to choose a different
 display.

 Available screen(s)

 The exact name of the menu entry depends on the display server
 software of your operating system (for example
 Screen wayland-0 on a Linux system
 running Wayland).

 If more than one screen is listed, you can select a different
 screen on which you want GIMP to be shown.
