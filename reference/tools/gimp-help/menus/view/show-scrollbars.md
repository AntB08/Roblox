## Show Scrollbars

 Scroll-bars
 Show/Mask scrollbars

 Show Scrollbars

 The Show Scrollbars command enables and
 disables displaying the scrollbars. It may be useful to disable them if
 you are working in
 full-screen mode.

 You can set the default for the scrollbars in the
 Image Window Appearance Preferences.

## Activating the Command

 You can access this command from the main menu through

 View
