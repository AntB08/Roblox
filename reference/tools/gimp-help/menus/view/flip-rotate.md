## Flip & Rotate (0°)

 Flip & Rotate

 You can access this submenu from the main menu through

 View
 Flip & Rotate (0°)
 .

 These commands change the view only, not on the image itself. If you want
 to change the image, go to: menuImage - Transform.

## Reset Flip & Rotate

 This command restores the view of the image to its original state.

 Activate:

 From the menu:

 View
 Flip & Rotate (0°)
 Reset Flip & Rotate
 .

 Using the shortcut key !.

## Flip Horizontally and Flip Vertically

 These commands change the view by flipping the image horizontally or
 vertically. If one of these is enabled you will see a check mark
 in front of the command.

 Activate:

 View
 Flip & Rotate (0°)
 Flip Horizontally
 .

 View
 Flip & Rotate (0°)
 Flip Vertically
 .

 This command opens a dialog that allows you to set the exact angle of
 rotation for the view. You can set the angle in the numeric input
 field, or drag the pointer in the circle to the desired angle.

 From the menu:
