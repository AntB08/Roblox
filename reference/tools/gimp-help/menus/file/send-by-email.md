## Send by Email

 Send by Email

 You can access this command from the main menu through

 File
 Send by Email…
 .

 This command opens a dialog with the name of the image to be sent via email
 (you can edit it). Clicking on the Send button opens
 your local default mail software with the image attached.

 This command is only available on Unix/Linux-like operating systems with
 the xdg-utils package installed, or if
 your GIMP version was explicitly created (compiled)
 with Sendmail support.
