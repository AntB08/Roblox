 This filter makes several copies of the original image, in a same or
 reduced size, into a bigger (new) image.

## Options

## Tile filter options

## Tile to New Size

 New width
 New height

 Input boxes and their arrow-heads allow you to enter the
 dimensions for the new image.

 The new image must be bigger than the original
 one. Else, you will get an image sample only. Choose
 sizes which are multiple of original sizes if you don't want to
 have truncated tiles.

 By default, New width and
 New height are linked, indicated by the

 chain symbol below the input boxes. If you want to set them
 separately, click on that chain symbol to unlink them.

 New image

 Keep this option checked to avoid modifying your original image.
