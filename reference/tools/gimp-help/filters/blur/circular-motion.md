## Overview

## The Circular Motion Blur filter

Original image

Filter applied

 This filters creates a circular blur around a center. The default center 
 is the center of the layer or selection. You can set center somewhere in 
 the layer and this center is applied to the layer or to a selection if it 
 exists.

## Activating the Filter

 This filter is found in the main menu under

 Here, you can set the rotation center. Sliders and spin buttons
 control the position of rotation center on horizontal and vertical
 axis. You can also click on the rectangle button with an arrow on
 the right and then click on the image to pick coordinates.

 Angle

 More Angle will result in more blurring in a circular direction.

 On-canvas controls

 This option (default) allows you to modify blur settings directly
 on canvas, for easier visual tweaking of blur settings. It displays
 a line with handle on both ends to move rotation center and
 transform.

 Press Alt key to only move rotation center without
 transforming.

 Press Ctrl key to rotate by 15° steps.
