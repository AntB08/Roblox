## Brush-tips:Outline  

### Question 

How to make an outline for a single brush stroke using Krita? 

Not really a brush, but what you can do is add a layer style to a layer, by [img: mouseright] a layer and selecting layer style. Then input the following settings: [img: Image demonstrating the layer style hack for this effect.] 

Then, set the main layer to multiply (or add a [Color to Alpha](../../reference_manual/filters/colors.xhtml#filter-color-to-alpha) filter mask), and paint with white: [img: Image demonstrating the layer style hack for this effect.] 

(The white thing is the pop-up that you see as you hover over the layer.) 

Merge into a empty clear layer after ward to fix all the effects.
