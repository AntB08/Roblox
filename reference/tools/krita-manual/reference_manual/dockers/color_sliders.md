## Color Sliders 

 

Deprecated since version 4.1: Replaced by the [Specific Color Selector](specific_color_selector.xhtml#specific-color-selector-docker) in 5.1  

A small docker with Hue, Saturation and Lightness bars. [img: ../../_images/Color-slider-docker.png] 

You can configure this docker via Settings ‣ Configure Krita… ‣ Color Selector Settings ‣ Color Sliders. 

There, you can select which sliders you would like to see added, allowing you to even choose multiple lightness sliders together.
