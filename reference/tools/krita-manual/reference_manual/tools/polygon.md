## Polygon Tool 

[img: toolpolygon] 

With this tool you can draw polygons. Click the [img: mouseleft] to indicate the starting point and successive vertices, then double-click or press the Enter key to connect the last vertex to the starting point. 

Shift + Z undoes the last clicked point. 

 

Added in version 5.1.2: [img: mouseright] wills also undo the last added point.
