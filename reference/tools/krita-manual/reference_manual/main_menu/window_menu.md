## Window Menu 

A menu completely dedicated to window management in Krita.  New Window

Creates a new window for Krita. Useful with multiple screens.  New View

Make a new view of the given document. You can have different zoom or rotation on these.  Workspace

A convenient access panel to the [Workspaces](../resource_management/resource_workspace.xhtml#resource-workspaces).  Close

Close the current view.  Close All

Close all documents.  Tile

Tiles all open documents into a little sub-window.  Cascade

Cascades the sub-windows.  Next

Selects the next view.  Previous

Selects the previous view.  List of open documents.

Use this to switch between documents.
